# VEGETAL · firmware para el M-VAVE FM-1

La familia vegetal de Tríadas como firmware para el FM-1: filotaxis (FILO), crecimiento ramificado con sistemas L
(RAMA), tropismos y circumnutación (TROP) y redes de raíces y micorrizas (RAIZ). Un firmware que solo muestra el
motor VEGETAL, construido sobre [Felucca](https://github.com/hugelton/Felucca) de Leo Kuroshita (Hügelton
Instruments), sin afiliación con sus autores.

Este repositorio guarda solo lo que VEGETAL agrega o cambia (`overlay/`). GitHub Actions toma Felucca en un commit
fijo, aplica `overlay/`, compila el firmware y publica en GitHub Pages el sitio con el instalador web.

Autor de VEGETAL: Ph.D. Mauricio Vásquez Arias, profesor titular – investigador asociado, Escuela de Artes y
Humanidades, Universidad EAFIT. Licencia: GPL-3.0 (como Felucca). Software experimental, sin garantía.
